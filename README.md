# Geometric Lib

Библиотека функций для вычисления параметров геометрических фигур.

## Структура проекта

- `circle.py` — функции для работы с кругом (area, perimeter)
- `square.py` — функции для работы с квадратом (area, perimeter)
- `docs/` — подробная документация проекта

## Документация

Подробная документация находится в папке [docs](docs/README.md)
